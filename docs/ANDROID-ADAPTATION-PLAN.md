## 1. Что уже есть и работает (состояние на 05.09.2026, обновлено)

### Слой рантайма (Termux-стиль proot-песочница)
- `runtime/` — установка и запуск DSH внутри изолированного рантайма:
  `RuntimeInstaller`, `ProotRunner`, `ProotCommandBuilder`, `BootstrapLayers`,
  `DebExtractor`, `HarnessOnboarding`, `NativeBuildConfig`, `RuntimePaths`,
  `TermuxPackageIndex`.
- Хост-рантайм ARM64 (`arm64-v8a`); для эмулятора x86_64 добавлена сборка
  нативных модулей (`koffi`, `node-pty` — собираются и валидируются).
- DSH-сервер запускается на `http://127.0.0.1:3080/?token=…`.
- `HarnessForegroundService` — foreground-сервис: Start/Stop/Reinstall/Reset,
  работает в фоне, WebView просто переподключается.
- Bootstrap «быстрый старт» из кэша; подтверждение Internal Testing Notice
  через `SETTINGS_YAML`.

### Оболочка приложения (Compose, `MainActivity.kt`)
- Терминальный экран запуска/установки: тёмная «консоль», стадия `● STARTING`,
  сворачиваемый журнал (`▸ Последние строки лога [n]`, по умолчанию свёрнут).
- Онбординг выбора языка: English / 中文 / Русский.
- Полноэкранный режим DSH («телефонный»): WebView на весь экран + нативные чипы
  в правом верхнем углу: 🌐 язык, ⚙ настройки, ⏹ стоп.
- Нативная шторка настроек (⚙):
  - API-ключ: сохранение/удаление в `~/.dsh/.credentials.yaml` (переживает
    перезапуски) + перезагрузка страницы;
  - язык приложения и язык DSH (en/zh синхронизируются в `settings.yaml`);
  - «Управление сессией»: режим работы / права доступа / сила мышления —
    драйвер кликает собственные пилю DSH (в т.ч. внутри Shadow DOM) и применяет;
  - доступ к файлам телефона (Android 11+ «All files access», `MANAGE_EXTERNAL_STORAGE`);
  - выбор папки рабочего пространства: `ACTION_OPEN_DOCUMENT_TREE` →
    регистрация workspace в `~/.dsh/storages/workspace.json` → рестарт сервера;
  - запись «Модель/провайдер» (точка входа в выбор модели).
- WebView: `domStorage`, file chooser (`onShowFileChooser` → системный выбор
  документов, мультивыбор), folder picker, clipboard-мост, фокус/клавиатура
  (`isFocusable`/`isFocusableInTouchMode`), devtools для отладки.

### Инжектируемый слой в страницу DSH (`WEBVIEW_DOC_START_JS`, `WEBVIEW_PAGE_FIX_JS`)
- Авто-скрытие панели «Add an API key» (защищённое — не закрывает модалки).
- Смягчение полной маски `_mask` (полупрозрачный фон вместо чёрного экрана).
- Ограничение ширины поповеров/диалогов на телефоне (`max-width: 92vw`).
- Фокус поля ввода по тапу (только вне открытых диалогов).
- **Авто-сворачивание сайдбара на телефоне**: DSH открывает панель 280px и
  сжимает колонку чата до ~132px (кнопки чата перестают быть доступны).
  Инъекция сворачивает сайдбар до 56px, колонка чата — полная (356px).
- **Русский слой** для DSH: словарь EN→RU, пере-сканирование по DOM-изменениям,
  SPA-навигации (`pushState`/`replaceState`/`popstate`), с обходом Shadow DOM
  (попапы доступа/моделей) и наблюдением за корнями.
- Page-fix переживает SPA-переходы: `ensureStyles()` пере-применяет стили,
  `autoCollapse()` повторяется, наблюдатели не теряются.

### Дополнения (05.09.2026, вечер — проверено на эмуляторе API 35, DSH 0.1.2-rc.1)

**Корневые причины «кнопки не работают» — найдены и устранены:**

1. **vh-коллапс WebView (главная)**: этот Android WebView вычисляет
   `100vh`/`100dvh` как `0px` (при корректном `window.innerHeight`). Все
   поповеры/меню/диалоги DSH с `max-height: calc(100vh - 24px)` получали
   высоту 0 — открывались, но были невидимы. Решение: `patchVhUnits()` в
   page-fix инъекции — патчит CSSOM, переписывая viewport-единицы в пиксели
   (оригиналы запоминаются, пересчёт на resize/новые стили). Проверено:
   `calc(-24px + 100vh)` → `calc(791px)`, меню режима 8px → 352px.
2. **`collectEls` без `return out`** (RU-слой): scan() падал
   `TypeError: els.length` до установки MutationObserver/интервала — перевод
   работал только для текстов первого прохода, shadow-DOM не переводился
   вовсе. Добавлен `return out` — RU-слой полнофункционален, включая пилюли
   в shadow-DOM («Только чтение», «Высокое»).
3. **Radix открывает поповеры на `pointerdown`**: драйверы шторки шлём полную
   pointer-последовательность (`window.__dshTap`), а не `el.click()`.

**Sidebar как drawer (по запросу пользователя):**
- На телефоне сайдбар всегда `position:fixed` overlay; кит-логотип
  открывает/закрывает панель (тап в левой верхней четверти 64×64 панели = toggle);
  тап вне панели закрывает; колонке чата резервирован гаттерин рельса
  (`centerCol { margin-left: 56px }`) — чат больше никогда не сжимается и не
  двигается. Проверено: 56 → 280 (fixed) → 56, чат статичен.

**Официальный репозиторий (deepseek-ai/deepseek-harness, ветка master):**
- Ключи провайдеров: `$DSH_HOME/.credentials.yaml` (write-only из UI),
  built-in провайдеры: `anthropic`, `openai`, `moonshotai`, `zai`; кастомные:
  Provider ID + Base URL + протокол (`openai-completions` / `openai-responses`
  / `anthropic-messages`) + модели, «Fetch available models».
- Remote API: клиент → хост через HTTP POST RPC (`/api`, cookie-авторизация
  через `GET /?token=`, cookie-секрет в `.credentials.yaml`); контроллеры
  `session/settings/workspace`. Для нативной интеграции пока используем
  файловые записи (settings.yaml / credentials / workspace.json) — формат
  стабильный.
- settings.yaml: `locale.preference` (en/zh); тема/пресет/права хранятся в
  клиентских стераджах DSH и меняются через сам диалог настроек DSH

**Сессия 2026-09-06 — «вкладки не листаются / из настроек не выйти / чата нет»:**
- **ГРИД-БАГ (корень «чат так и не появился»)**: WebView криво раскладывает
  auto-placement грида `pI_x6G_frame` при растворении `display:contents`
  обёрток — панель «Сведения» (`detailsCol`) попадает в дорожку чата
  (356px), а чат (`centerCol`) схлопывается в 0px, и это ДОЖИВЕТ даже при
  «закрытой» панели (шаблон `56px minmax(0,1fr) 0px`). Лечение: явное
  закрепление колонок `[class*="sidebarCol"]{grid-column:1}` /
  `centerCol→2` / `detailsCol→3` с `!important` в телефонном media-блоке.
  Проверено: center 300px (чат виден), details 0px ✅ (qa/emu-14-chat-fixed.png).
- **Настройки — фуллскрин и скроллы**: диалог `[role=dialog][class*=_panel]`
  растянут offset-ами (left/top/right/bottom:0 + width/height:auto — не

  строка с overflow-x (sw 510 > cw 388, «Пресеты агентов» тапается ✅).

  после прокрутки вниз, выход работает ✅ (qa/emu-15-settings-final.png).
- **Клик-хендлер сайдбара**: проверка `closest('[role="dialog"],…')`
  перенесена ПЕРЕД whale-уголком 64×64 (иначе глотал кнопки диалогов).
- **Язычок справа**: дублирующая кнопка 🌐 удалена — язык остался в ⚙
  (NativeSettingsSheet); мёртвое состояние langOpen убрано.
- **Словарь RU**: + Details-панель («Сведения», «Скрыть сведения»), настройки

- **EADDRINUSE-цепочка** (из прошлой сессии, в этой сборке): host-sweep

## 2. Открытые проблемы (что просил пользователь и что ещё не доделано)

1. **«Панель гигантская, кнопки не работают»** — причина найдена: раскрытый
   сайдбар DSH (280px) сжимает колонку чата. Авто-сворачивание добавлено и
   подтверждено (sidebar=56, center=356). **Решено**: на viewport ≤640px
   сайдбар теперь `position:fixed` overlay, не сжимает чат. Проверка на
   эмуляторе/устройстве required.
2. **Перевод попапов доступа/моделей** — РЕШЁН: collectEls fix + RU-слой
   переводит и shadow-DOM; при языке RU DSH принудительно ставится на EN
   (`syncDshLanguage("ru") → preference: en`). Словарь пополнен ключами из
   диалога настроек 0.1.2-rc.1 (Permission, Agent presets, Font size,
   подтверждение Full access). Длинные абзацы предупреждений (>60 символов)
   остаются на английском.
3. **Блокировка ввода/фантомная подложка** — маска смягчена, добавлен tap-focus
   + tap-to-dismiss (клик по маске вызывает Escape + закрытие диалога +
   автофокус композера). Полностью реализовано в JS-инъекции.
4. **Выбор провайдера и модели** из настроек/чата — только частично (есть усилие,
   выбор модели открывает меню). Нет полного списка провайдеров/моделей и записи
   ключей по провайдерам из нативного UI.
5. **Системный выбор папки рабочего пространства** — код есть, сквозной проверки
   и подхвата в браузере каталогов DSH до конца не сделано.
6. **Файлы в чат** — file chooser подключён, но реальный сценарий прикрепления
   (drag&drop-мост, если DSH не использует `<input type=file>`) не проверен.
7. **Клавиатура/фокус** — на устройстве нужно подтвердить открытие клавиатуры в
   композере, отсутствие «залипания» после модалок.
8. **RU внутри DSH**: DSH из коробки имеет только EN/中文; RU — только наш слой.
   Полнота перевода ограничена словарём; систематический сбор непереведённых
   строк и расширение словаря — постоянная задача.

## 4. Критерии «готово» для текущего спринта
- Сайдбар не раскрывается «гигантским»: колонка чата всегда ≥ ~85% ширины
  экрана, либо панель — закрываемый оверлей.
- Все кнопки чата реагируют на тап при свёрнутой панели.
- Попап доступа/моделей в RU-режиме показывает русские подписи.
- После открытия и закрытия любого меню/диалога композер снова получает фокус,
  клавиатура открывается.
- Сборка `:app:assembleDebug` и `:app:testDebugUnitTest` — зелёные.
