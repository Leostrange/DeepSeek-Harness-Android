# 0.2.0-rc2 RU experimental port2 — 2026-10-06

Исправлены два сбоя, показанные на телефоне после установки port1.

## Подготовка среды: METADATA_LIMIT

`RuntimeTools.assetObject` использовал общий строгий JSON-парсер с лимитом строки 16384 символа. В подписанном `ru-preset-picker-patch.json` строка замены содержит 58831 символ. Теперь только чтение встроенных JSON-активов явно разрешает строки до общего лимита документа 2 MiB. Чтение пользовательских архивов по-прежнему ограничивает строки 16 KiB; лимиты байтов, глубины, количества полей и проверка повторных ключей сохранены.

## Экспорт журналов: PARENT_LINK

Временный файл журнала создан в framework cacheDir, часто представленном через системную ссылку `/data/data`. Строгий AndroidBackupFileSystem правильно отклоняет родительские ссылки, но DownloadsExport ранее передавал ему этот нерешённый framework-путь. Новый PrivateExportSource разрешает только Android-authorized dataDir, проверяет соответствие filesDir/cacheDir и заново строит путь внутри него. Приватные вложенные ссылки, выход за разрешённый каталог и `..` остаются запрещены. Проверка исходного файла через lstat/fstat и проверка экспортированного URI сохранены.
