# DSHA RC2 RU test5: исправление первой установки

Основание: DSHA-error-log-20261003-212115.txt, realme RMX5000, Android 16, test4/148. Две попытки первой установки завершались на этапе подготовки инструментов до запуска Web.

Причина: рецепт ru-preset-picker-patch.json сначала заменял data-tip, а последняя правка повторно меняла тот же результат. Архив содержал финальный код, но нативный ExactTextPatch при повторном применении первой правки не находил ни исходного, ни промежуточного текста. Проверка архива на соответствие сборщику проходила, поэтому предыдущие проверки эту ошибку пропустили.

Исправление: исходный data-tip сразу преобразуется в финальный атрибут; зависимая правка удалена. Прочие изменения test4 сохранены. Проверки несовпадения неизвестного исходника и защиты пользовательских данных остаются в силе.

Добавлен tools/test-installed-russian-patches.py: компилируется реальный Java ExactTextPatch, а девять рецептов дважды применяются к байтам модулей из поставляемого dsh-runtime.bin. Во всех случаях код остаётся неизменным. Браузерные проверки и проверки редактирования/сохранения пресетов прошли. Итоговый APK проверяется по подписи, версии и всем 117 входным активам.

APK: DSHA-0.1.7-rc2-RU-standard-test5.apk, versionCode 149. Пакет и ключ подписи сохранены для обновления установленной RC2 RU. Удаление приложения или очистка данных для этого исправления не требуются. Физический запуск на телефоне пока не проверен.
