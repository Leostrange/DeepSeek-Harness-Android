# DSHA: исправления нового списка задач

Источник: DSHA-new-tasklist.zip, четыре задачи и пять фотографий. Этот список ведётся отдельно от предыдущих замечаний и остаётся открытым для дополнений.

1. Добавлен перевод отображаемых названий и описаний экспериментальных официальных компонентов и восьми установленных плагинов из снимка. Перевод применяется через реальный LocaleRuntime.resolveText, учитывает выбранный язык и сохраняет явный авторский русский перевод. Технические идентификаторы, пакеты, конфигурация и пользовательские данные не переименовываются. Заголовки карточек инвентаря и главной страницы управления плагинами также проходят через локализацию, включая имена без авторского заголовка. Для неизвестных сторонних плагинов собственного каталога переводов нет; их авторские описания сохраняются.
2. Мобильные кнопки снова подключены к исходному списочному слоту действий заголовка. Два реальных элемента размещены у краёв первой строки. Тест использует настоящий MobileNavToggle и реальные SVG-иконки, проверяет видимость, координаты и callbacks. «Агенты» и «Задачи» имеют одинаковую высоту и вертикальное выравнивание.
3. Положение панели задач вычисляется по фактическому заголовку и обновляется при изменении окна. Старое общее мобильное правило top=80px больше не перекрывает её положение. Панель располагается на 8 px ниже заголовка, имеет сопоставимую с панелью команды ширину, скругление и фон темы; сохраняет список, раскрытие вывода, остановку и очистку завершённых заданий.
4. Пустая панель остаётся открытой и показывает «Заданий нет», «No tasks» или «暂无任务». Исправлено автоматическое закрытие при нулевом количестве. После очистки завершённых заданий также показывается пустое состояние.

Проверки: реальный LocaleRuntime для перевода и трёх языков пустого состояния; реальные компоненты с полными мобильными стилями на 280/320/360/600 px; меню с завершённым заданием и его очистка; сохранение кастомных пресетов; строгие контракты Typert; два повторных прохода всех одиннадцати рецептов настоящим Java ExactTextPatch по готовому архиву. Сборка, Android unit-тесты и lint отражены в DSHA-build-verification.json. Новое тестирование на физическом телефоне не выполнено.

Сборка: DSHA-0.1.7-rc2-RU-standard-test6.apk, пакет com.dsh.client.rc2ru, versionCode 150, тот же ключ подписи. Устанавливается поверх предыдущей RC2 RU без удаления приложения и очистки данных.
