# Test17: оформление меняется только по настройкам пользователя

Проверен APK Test16: вкладку «Темы» добавляет встроенный `dsh-any-background` версии 0.2.8. Его `lib/client.js` в APK совпадает с локальным исходником. Прозрачность появлялась даже при значениях 100%: глобальные CSS-правила заменяли фоновые токены хоста неопределёнными переменными плагина. Отдельное правило всегда делало контейнеры блоков кода прозрачными.

В Test17 переопределения поверхностей включаются только при настроенной палитре либо изменённой прозрачности. При отсутствии настроек сохраняются цвета, размытие и позиционирование хоста. Для ручного изменения прозрачности без выбранного цвета используются цвета текущей темы, без генерации новой палитры. Возвращение к 100% снимает переопределения и восстанавливает исходные фоны. Отключение плагина восстанавливает только те свойства, которые он изменял.

Чтение сохранённых настроек больше не запускает миграцию прозрачности и запись конфигурации. Серверные и клиентские значения прозрачности для новой установки равны 100%. Существующие пользовательские значения сохраняются, включая исторические 85%/93%. При запуске не извлекается новый цвет из сохранённых обоев. Явные действия пользователя и ранее включённые им ротация/расписание сохраняют свою функциональность.
