# DSHA RC2 RU: исправления после проверки на телефоне

Дата: 03.10.2026. База v0.1.7-rc2, commit ac2767272d04da1d71b310137f1925e9e8950d53. Рабочее дерево C:/Users/xmeta/projects/DSHA/work/upstream.

## Причины дефектов предыдущего APK

Фотографии из «Баги» подтвердили, что предыдущая проверка была недостаточной. Наличие перевода в каталоге не означало покрытие новых экранов. Дополнительная регистрация agentPresets/save содержала строгие кодеки без обязательного typeSymbol: настоящий Typert отвергал пакет определений, и модели, плагины и выбор папки становились недоступны. Языковой мост обрабатывал пакетную регистрацию словарей, но пропускал форму register(namespace, language, dictionary), используемую в том числе выбором папки.

## Исправлено в новой сборке

- Кодеки сохранения имеют корректные typeSymbol на сервере и клиенте. Проверка использует настоящий валидатор Typert и реестр API RC2; определения directoryPicker/list, llm/listProviders и plugin manager сохраняются. Защитный SRC fallback не включён.
- Языковой мост поддерживает обе формы регистрации, корректное удаление словарей и приоритет собственного русского перевода плагина.
- Обработчики этапов запуска и аварийных статусов теперь учитывают русский язык; неизвестные диагностические сообщения и исходный вывод команд сохраняются.
- Каталог Android дополнен по реальным Java-вызовам и XML, включая обслуживание, модели, восстановление, хранилище, резервирование, DNS, PiP, разрешения и статусы. Проверено 3701 парных записей и отсутствие пропусков среди найденных литеральных UiText.text. Дополнены отдельные диагностические строки и описания встроенных плагинов; сторонние описания остаются авторскими. 2357 найденных статических веб-ключей имеют русский перевод с сохранёнными подстановками. Это аудит доступных статических строк, а не заявление о проверке каждого экрана на телефоне.
- До приветствия и подготовки среды появляется отдельный выбор русского, английского, китайского или системного языка. Выбор сохраняется и не запрашивается при следующем запуске; обновление предыдущей тестовой сборки также показывает новый онбординг один раз.
- Встроенный DevTools включён в список пресетов и в пакет DSH. Его состав совпадает с agent.cordis.yml из присланного devtools-preset.tar.gz. Исходный prompt сохранён. Присланные установочные скрипты не запускались; упоминаемые в prompt сторонние инструменты не объявляются установленными автоматически.
- Редактор имеет вкладки «Промпт» и «Состав», карточки компонентов, включение/выключение, изменение порядка, добавление/удаление и расширенный YAML. Условные !!js сохраняются как данные и не исполняются редактором. Встроенные пресеты, включая DevTools, защищены в интерфейсе и на сервере. Редактируются только пользовательские источники, допускающие запись.
- Сохранение проверяет исходную версию, дожидается реальной записи Include.flushWrite и откатывает конфигурацию при ошибке. Черновик сохраняется в открытом окне; отмена изменений требует подтверждения. Некорректный YAML открывается в текстовом режиме вместо падения редактора.

## Проверки

Полные наборы Gradle Standard и Low: по 816 тестов, 815 успешных и один штатный пропуск; ошибок нет. StandardRuTrial и Lint проходят: 0 ошибок, 512 предупреждений. Итоговый APK, подпись и точные хеши встроенных assets фиксируются в DSHA-build-verification.json. Отдельно прошли 45 Java-тестов языка и динамических статусов, lifecycle словарей RC2, настоящий контракт Typert, 20 мобильных сценариев, сохранение/повторное чтение и откат редактора, изменение prompt и состава с сохранением !!js, сравнение DevTools с присланным YAML, 12 тестов recovery assets и фактический browser recovery overlay EN/ZH/RU.

## Сборка и данные

Файл DSHA-0.1.7-rc2-RU-standard-test2.apk сохраняется в корень проекта. Пакет com.dsh.client.rc2ru, версия 0.1.7-rc2-ru-test2, код 147, Android 11+, arm64. Это обновление предыдущего отдельного приложения DSHA RC2 RU с тем же локальным тестовым ключом, debuggable=false. Официальный исторический сертификат E7E3 не подменяется. Порты 3380/3381/3390 и Documents/dshdata-rc2ru остаются прежними; оригинальные APK и данные Alpha сохраняются. Для старого имени DSHA-0.1.7-rc2-RU-standard-test.apk в корне также используется исправленный APK, чтобы исключить повторную установку дефектного файла.

DSH пересобран из dependency lock, без исполнения Linux/arm64 install scripts на Windows. Ubuntu tools восстановлены по 28 locked deb. Оптимизированный rootfs взят из исходного RC2 APK. Независимые recovery archives проверяются по неизменённому recovery lock. Descriptor и package proofs пересчитаны штатными генераторами. Большие архивы не включены в текстовый patch.

## Осталась проверка на устройстве

ADB-устройство не подключено. Проверки на хосте не заменяют холодный запуск Android, реальную загрузку всей среды, список моделей и плагинов, выбор проекта, новые и активные сессии после правки пресета. Не выполнены проверки каждого экрана и большого шрифта на телефоне, Low APK/Android 6–7 и всех внешних провайдеров моделей. APK не публиковался. После установки test2 нужно подтвердить эти сценарии на телефоне; предварительный статус «всё переведено и работает» не используется.
