Рабочая копия: `C:\Users\xmeta\projects\DSHA\work\upstream-020-ru`, ветка `port/020-ru`. Исходная копия `work/upstream` и APK Test17 остаются прежними.

Перед слиянием создан полный снимок пользовательских tracked/untracked исходников `b01c0ab6b38d42a934bb453fdef082d85f3da422`. Бинарный diff исходной рабочей копии также сохранён рядом в `work/rc2-ru-port-snapshot.patch`.

## Что перенесено

- Русский язык Android/Web, выбор языка при первом запуске, сообщество и описания плагинов.
- Мобильная вёрстка, симметричные группы Чат/Траектория и Агенты/Фоновые, меню агентов/субагентов, отдельные задачи, анимация полосок и сенсорная навигация.
- Скорость, счётчики и расходы под полем ввода; кликабельные оригинальные диалоги подробностей.
- Полноэкранный мобильный редактор кастомных пресетов, защита встроенных пресетов, сохранение YAML, проверка содержимого и конфликтов записи.
- Все пять добавленных community-плагинов, их переводы, исправление здоровья сессии и нейтральные настройки оформления Test17. Плагин оформления сохранён в исправленной версии 0.2.8; полупрозрачные defaults 0.3.5 не импортированы.
- Язык ответа модели, исправления разрешений и авто-проверки, режим DevTools и локальная интеграция Android.
- Отображение прогресса распаковки перенесено из прежнего ProotBootstrap в новый ColdBundleExtractor, включая чтение отдельных архивов Ubuntu/DSH.

Новая архитектура upstream сохранена: регистрация плагинов из JSON/сгенерированного Java, единый реестр runtime-патчей, транзакционный установщик, новая обработка жизненного цикла WebView, системная/светлая/тёмная нативная тема. Старые удалённые upstream патчи навигации и установочные скрипты не возвращались в новую архитектуру; пользовательские функции подключены через её актуальные точки расширения.

## Проверки переноса

13 пользовательских runtime-рецептов проверены на точных исходниках закреплённой версии 0.2.0-rc.2; все точки замены присутствуют. Архив собран из npm lock с отключёнными install scripts. Проверка реального ExactTextPatch повторно применяет рецепты к байтам архива и подтверждает отсутствие повторной модификации.

Браузерные сценарии используют React и компоненты нового runtime: нейтральная тема/явные изменения/сброс, сохранение opacity, здоровье сессии, статистика и исходные обработчики подробностей, пресеты и откат ошибочной записи, мобильные страницы 280–900 px, вопросы/планы/модели/плагины, заголовок, поповеры, PiP и боковое меню. Тестовые pending-объекты обновлены под новые snapshot/liveKeys/focus методы DSH 0.2; реальное поведение компонентов проверяется, а не заменяется старой версией.

Полный прогон: 1205 тестов, 0 падений, 0 ошибок, 4 пропуска тестовым окружением. После добавления терминала отдельно повторно проверены история и владелец сессий. Физическое Android-устройство не подключено; проверка запуска на телефоне не выполнена. Результат проверки APK приведён ниже.

Для больших Windows JVM-сценариев (130 операций, история из 1000 записей и пакетный поиск архивов) тестовый адаптер один раз определяет том контролируемой временной папки. Все чтения метаданных, проверки содержимого, синхронизации и транзакции остаются реальными; проверки границ томов и производственный файловый адаптер не изменены.

## Терминал AB UB

Исследован предоставленный AB-UB.apk (com.io.ab.ub, 1.0.0). В нём используется тот же Termux TerminalView/TerminalSession и 2000 строк scrollback, что уже есть в DSHA. Перенесена терминальная оболочка поверх штатного PTY DSHA: две строки по семь клавиш (ESC, /, -, HOME, вверх, END, PGUP; TAB, CTRL, ALT, влево, вниз, вправо, PGDN), одноразовые модификаторы, копирование полного вывода, bracketed paste, переключение клавиатуры, масштабирование, список сессий, переименование, закрытие всех с подтверждением и история вывода из 40 записей. При восстановлении истории старый shell не объявляется живым; новая сессия создаёт новый процесс. Файловый менеджер и установщик дистрибутивов AB UB не переносились согласно уточнению пользователя «Только терминал».

JADX использован только для анализа APK. В приложение не добавлялись обфусцированные классы, ресурсы и библиотеки AB UB; используется уже включённый движок Termux и существующий управляемый runtime DSHA.
