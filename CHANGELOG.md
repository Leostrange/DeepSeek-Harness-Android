# CHANGELOG

Все заметные изменения в DSHA (DeepSeek Harness для Android).

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

---

## [0.2.0] — 2026-09-06

### Хранение данных

- **Автобэкап чатов** — при остановке демона (кнопка ⏹ или система) сессии, рабочие пространства, профили и настройки архивируются в `/sdcard/DSHA-backup/chats-latest.zip` (до 5 датированных копий). Ключи API в бэкап не попадают.
- **Автовосстановление** — при запуске, если хранилище `.dsh/sessions` пусто (переустановка, сброс среды), чаты распаковываются из последнего архива до старта сервера; Harness не видит пустую сессию.
- **Ручная кнопка** «Сделать резервную копию чатов» в настройках ⚙.

### Android SDK в песочнице

- **Автоустановка при первом запуске** — встроена в цепочку загрузки (RUNTIME → DSH → SDK → NATIVE → UI), до появления окна чата. Маркер `.installed` создаётся только при полном успехе.
- **JDK 17** — из официального Termux-репозитория (`openjdk-17`, bionic-сборка); glibc-JDK (Temurin) не запускается в песочнице. Зависимости (libandroid-shmem, zlib и др.) резолвятся автоматически по `Packages.gz` (node-парсер); `.deb` распаковываются встроенным node ar-ридером + tar.
- **Gradle 8.13** — распаковывается через JDK `jar` (unzip отсутствует в песочнице).
- **Android cmdline-tools** + `platform-tools`, `platforms;android-35`, `build-tools;35.0.0` — через `sdkmanager`.
- **Статус в ⚙**: текущие версии JDK/Gradle, кнопки «Установить SDK» и «Обновить SDK» (forceUpdate удаляет маркер).

### Обновление DeepSeek Harness

- Кнопка **«Обновить DeepSeek Harness»** в ⚙ — ставит `@deepseek-ai/dsh@latest` из npm-регистрации (официальный канал), пересобирает нативные модули, перезапускает сервер.
- В логах выводится версия пакета до и после обновления.
- При ошибке npm прежняя версия сохраняется; сервер поднимается в любом случае.

### Чат — layout и UX

- **Композер над клавиатурой** — `imePadding()` на корневом контейнере; на targetSdk 35 `adjustResize` мёртв (edge-to-edge форсирован), без этого композер оставался под клавиатурой.
- **Чат прижат к низу** — пустая сессия DSH центрировалась по вертикали (justify-content: center); заменено на `flex-end` — композер у нижнего края.
- **Скролл истории починен** — `justify-content: flex-end` в флекс-колонке при переполнении не даёт прокрутиться к началу; JS-переключатель `dsh-overflow` возвращает `flex-start` когда контент длиннее контейнера.
- **Поповер модели/мышления** — панели Radix вылетали за правый край экрана; добавлено ограничение `max-width: calc(100vw - 12px)` на дочерние элементы `[data-radix-popper-content-wrapper]`.
- **Симметричные поля** — при скрытой левой панели frame получает `padding: 0 12px` вместо 24px (было асимметрично).
- **Возврат панели по кнопке** — состояние чипа-тоггла «◧/◨» терялось при закрытии язычка (каждый тап снова «скрывал» панель); теперь страница сама тогглит класс и возвращает фактическое состояние; localStorage синхронизируется при загрузке.

### Прикрепление файлов

- В конце списка команд (`+` в чате) появилась кнопка **«📎 Добавить файл или фото…»** (инъекция через MutationObserver в поповер Radix).
- **Диалог на три опции**: файловый менеджер Android (любые файлы), галерея (фото, `image/*`), папка проекта.
- Папка проекта → нативный браузер папок (от `/sdcard`) → `registerWorkspace` → рестарт — папка становится рабочим пространством DSH.
- Прикрепляемые файлы: **любой тип** (DSH запрашивал только картинки), множественный выбор.

### Session log

- Кнопка **Session log** в DSH генерирует ZIP через `blob:`-ссылку; WebView никогда не вызывает `DownloadListener` для `blob:` — теперь клики по `<a href="blob:...">` перехватываются JS-кодом, байты извлекаются через `FileReader` → `data:base64` → нативный мост `AndroidClipboard.saveDownload` → сохранение в «Загрузки» через MediaStore.

### Шрифты

- **5 бесплатных (SIL OFL) гарнитур** встроены в APK: Inter (876 КБ), Lora (212 КБ), JetBrains Mono (187 КБ), IBM Plex Sans (267 КБ), IBM Plex Mono (136 КБ).
- **Регистрация через `@font-face`** — base64 data URL инжектируется в страницу; восстанавливается после перезагрузки (наAttach).
- **Масштаб интерфейса** — через CSS `zoom` на `#root` (DSH / 95% / 110% / 125% / 140%); масштабирует всё, включая px-размеры.
- **Межстрочный интервал** — глобально через CSS `line-height` на `body, #root` (DSH / 1.4 / 1.6 / 1.8).
- **Живое превью** — `AndroidView` с `TextView` + `Typeface.createFromAsset` — мгновенный визуальный отклик.
- Значения сохраняются в SharedPreferences (`chat_font_zoom`, `chat_font_family`, `chat_line_height`) и localStorage (`dshFontZoom`, `dshFontFamily`, `dshLineHeight`); применяются через `window.__dshApplyFont()` при загрузке и при каждом изменении.

### Иконка

- **Новая иконка** (не кит): adaptive-icon (API 26+): drawable-фон (градиент navy → DSH blue → violet, 315°) + vector foreground (белый терминальный промпт `>_`, viewport 108dp, safe-zone). Legacy PNG сгенерированы Pillow для mdpi–xxxhdpi (скруглённый квадрат + круг).

### Внутренние улучшения

- **Фильтр linker-warning** — строки `WARNING: linker` / `CANNOT LINK` отсеиваются из `harness.log` (косметика, не содержательная ошибка).
- **Skeleton-пилюли** — пока каталог моделей DSH загружается, в ряду композера пульсируют два белых прямоугольника; исчезают при появлении настоящих пилюль.
- **Toast-фидбек пикеров** — SAF-пикер и нативный браузер папок показывают уведомление об успехе / неудаче (раньше молчали).
- **CI-patches синхронизированы** — `ci/patches/HarnessForegroundService.kt` и `RuntimeInstaller.kt` перезаписаны из актуальных android-исходников; workflow собирает из зеркала + патчей.
- Добавлен `.gitignore` (build-артефакты, qa-скриншоты).

### Известные ограничения

- SDK: если «Установить SDK» нажималась в сборке до исправления резолвера, маркер `.installed` битый → нажмите «Обновить SDK» (forceUpdate).
- Панель «Сведения» при открытии перекрывает чат (закрывается крестиком, корень — WebView-баг раскладки DSH).
- Длинные тексты DSH частично остаются на английском (предел словаря 60 символов).
- Composer placeholder «Describe what you want to build…» не переведён (атрибут placeholder, не текстовая нода).
- `adb start-foreground-service` не может дёрнуть не-экспортированный сервис — автоматизация только через UI-тапы (Permission Denial).

## [0.1.0] — 2026-09-06

Первый публичный релиз.

### Функциональность

- DeepSeek Harness (`dsh web`) в proot-песочнице на устройстве: Node.js + Termux-совместимый рантайм, форграунд-сервис, WebView.
- Мобильный UI: сайдбар-шторка поверх чата (кит-тогл обоих направлений), полноэкранные настройки DSH с горизонтальным скроллом вкладок и вертикальным скроллом опций; фиксированный заголовок с крестиком.
- Русский перевод: словарь EN→RU (~150 записей), MutationObserver + debounce, shadow-DOM, при русском языке DSH держит `en`.
- Темы: светлая / тёмная / системная (Compose).
- Язык приложения: русский, English, 中文.
- Рабочие пространства: SAF-пикер → `/sdcard/...` → `registerWorkspace` → рестарт; нативный браузер папок; Toast-фидбек.
- API-ключ DeepSeek: ввод в ⚙, запись в `.credentials.yaml`, экспорт в `DEEPSEEK_API_KEY` env при запуске `dsh web`.
- Приватное хранилище: ключи, сессии и настройки в приватном каталоге приложения.
- Доступ к хранилищу: MANAGE_EXTERNAL_STORAGE для `/sdcard` доступа из песочницы.

### WebView-фиксы

- **vh-collapse** — `100vh` / `100%` разрешаются в 0px в этом WebView → `patchVhUnits()` перезаписывает CSSOM в px по `window.innerHeight`.
- **Грид-баг** — auto-placement `display:contents` в Chromium-версии эмулятора ставит `detailsCol` в дорожку чата → `centerCol` схлопывается в 0px; фикс: явные `grid-column: 1/2/3` с `!important`.
- **Radix popovers** — открываются на `pointerdown`, а не click; `__dshTap` отправляет полную последовательность pointerdown/mousedown/pointerup/mouseup/click.

### Надёжность запуска

- **EADDRINUSE-цепочка**: `killHostStaleDshProcesses()` (host-side `/proc` sweep + `SIGKILL`) перед запуском → adopt работающего сервера с восстановлением token URL → retry.
- `restartHarness()` при сохранении ключа API (env применяется только при старте).

### CI

- GitHub Actions workflow (`android-build.yml`): реконструкция android-исходников из base64-частей + патчи из `ci/patches/`, unit-тесты, `assembleDebug`, аплоад артефакта; триггер на push в `main` и `temp`.
- Репозиторий: clean orphan `main`, README в стиле Mr.Comic (badges, Возможности, Архитектура, Сборка, Приватность), топики.
