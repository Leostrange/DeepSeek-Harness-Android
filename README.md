# DSHA для Android · русская версия

Русифицированная сборка DeepSeek Harness Android на базе [DSH-APP/DSHA](https://github.com/DSH-APP/DSHA).

## Актуальный выпуск

**DSHA 0.2.2 RU · build364** — Android11+ / arm64-v8a.

[Скачать APK и исходники](https://github.com/Leostrange/DeepSeek-Harness-Android/releases/tag/v0.2.2-ru-build364)

- Дополнены переводы Android и веб-клиента: установка, диагностика, восстановление, загрузка и настройки.
- Добавлены недостающие описания встроенных плагинов.
- Исправлено переполнение страниц настроек «Модели» и «Встроенные плагины».
- Убрана дублирующая кнопка боковой панели и отцентрирована панель команды.
- Исправлено изменение высоты чата при открытии и скрытии клавиатуры.
- Устранён METADATA_LIMIT в рецептах перевода.
- Отцентровано отдельное окно списка субагентов; исправлены названия действий, статусы, счётчики и время.
- Выбранный язык передаётся модели для новых пояснений к инструментам и названий субагентов; технические имена и история сохраняются.

Пользователь подтвердил build363 на своём Android16. Build364 — подписанное обновление ресурсов той сборки, проверенное программно; новая проверка на телефоне ещё ожидается.

## Исходники

Актуальные исходники тестовой сборки находятся в приложенном к релизу **DSHA-0.2.2-RU-build364-source.zip**. Этот архив сохранён вместе с APK; автоматический GitHub Source code.zip содержит снимок этого репозитория и не заменяет архив исходников сборки.

[Официальный PR #253](https://github.com/DSH-APP/DSHA/pull/253) обновлён (Draft). Актуальный код находится в связанном форке Leostrange/DSHA, ветка fix/russian-ui-and-mobile-layout. [Материалы вклада](upstream-contribution/README.md) содержат также исторический патч первого пакета. Пакет после ревью содержит дополнительные исправления подписей и манифестов; он отдельно от исходников уже проверенного APK.

Прежний Kotlin/Compose-прототип в `android/` и `android-build-src.zip` сохранён как история. Он не является исходной базой build364; старый workflow нельзя использовать для сборки актуального APK.

## Установка

Скачайте APK из актуального релиза. Возможность обновления поверх другой сборки зависит от совпадения пакета и сертификата подписи. Ключи подписи и пользовательские данные не публикуются.
