# DSHA для Android · русская версия

Русифицированная сборка DeepSeek Harness Android на базе [DSH-APP/DSHA](https://github.com/DSH-APP/DSHA).

## Актуальный выпуск

**DSHA 0.2.2 RU · build363** — Android11+ / arm64-v8a.

[Скачать APK и исходники](https://github.com/Leostrange/DeepSeek-Harness-Android/releases/tag/v0.2.2-ru-build363)

- Дополнены переводы Android и веб-клиента: установка, диагностика, восстановление, загрузка и настройки.
- Добавлены недостающие описания встроенных плагинов.
- Исправлено переполнение страниц настроек «Модели» и «Встроенные плагины».
- Убрана дублирующая кнопка боковой панели и отцентрирована панель команды.
- Исправлено изменение высоты чата при открытии и скрытии клавиатуры.
- Устранён METADATA_LIMIT в рецептах перевода.

Пользователь подтвердил запуск и исправления на своём Android16. Это не проверка всех устройств и версий Android.

## Исходники

Актуальные исходники проверенной сборки находятся в приложенном к релизу **DSHA-0.2.2-RU-build363-source.zip**. Этот архив сохранён вместе с APK; автоматический GitHub Source code.zip содержит снимок этого репозитория и не заменяет архив исходников сборки.

[Правки для официального проекта](upstream-contribution/README.md) — полный Git-патч и инструкция применения к указанной официальной базе. Пакет после ревью содержит дополнительные исправления подписей и манифестов; он отдельно от исходников уже проверенного APK.

Прежний Kotlin/Compose-прототип в `android/` и `android-build-src.zip` сохранён как история. Он не является исходной базой build363; старый workflow нельзя использовать для сборки актуального APK.

## Установка

Скачайте APK из актуального релиза. Возможность обновления поверх другой сборки зависит от совпадения пакета и сертификата подписи. Ключи подписи и пользовательские данные не публикуются.
